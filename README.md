# ConveyorQuote — Cotizador PWA

Primera etapa del cotizador de sistemas transportadores: estructura de la aplicación e interfaz responsive.

## Tecnología
- React + TypeScript
- Vite
- vite-plugin-pwa
- Lucide React

## Ejecutar localmente
```bash
npm install
npm run dev
```

## Compilar
```bash
npm run build
```

## Alcance de esta versión
- Pantalla de inicio de sesión de demostración.
- Panel inicial y navegación para vendedor.
- Menús de administración para usuarios, materiales, precios y configuración.
- Vistas iniciales de cotizador y clientes.
- Diseño adaptable a computadora, tablet y móvil.
- Configuración base de instalación PWA.

**Importante:** esta entrega es únicamente un prototipo visual. El inicio de sesión no valida credenciales, el selector de rol solo permite visualizar los menús y los datos no se guardan. La autenticación, los permisos reales, la base de datos y los cálculos se implementarán en etapas posteriores.
